# Listening gallery staging

The local studio is a Python application and cannot run on static GitHub Pages. Run `python studio.py` locally for composition/upload/verification. The original `index.html` remains the historical six-palette token demo.

For a Pages listening gallery, use the repository root and open `gallery.html`; its relative links point only to committed synthetic WAV fixtures. Nothing has been deployed publicly in this private review. After Ashleigh approves publication, select the root as the Pages source or use an artifact workflow and set the desired landing page. A private repo does not automatically make its Pages site private.
